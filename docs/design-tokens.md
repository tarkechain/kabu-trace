# デザイントークン

最終更新: 2026-09-23
関連文書: docs/requirements.md

この文書は視覚仕様の唯一の情報源である。
実装時、ここに定義されていない色・サイズ・フォントを使用してはならない。
必要が生じた場合は、勝手に追加せず、この文書への追加を提案すること。

---

## 1. 方向性

- 参照するもの: なし（既存の参照サイトは指定せず、本サイト独自の方向性として下記を確定値とする）
- 参照のうち真似る点: -
- 参照のうち真似ない点: -
- 印象を表す語（3語以内）: 誠実・明快・静か
- 避けたい印象（対義語で境界を示す）: 「明快」だが「無機質」ではない

## 2. 配色

| 用途 | 変数名 | 値 | 備考 |
|---|---|---|---|
| 背景 | --color-bg | #FFFFFF | |
| 本文 | --color-text | #1A1A1A | 背景とのコントラスト比 17.4:1 |
| 補助文字 | --color-text-muted | #6B7280 | |
| アクセント | --color-accent | #1F4E79 | リンク、強調 |
| 境界線 | --color-border | #E5E7EB | |
| 面（カード等） | --color-surface | #F7F8FA | |

- ダークモード: 対応しない
- 上記以外の色を使用しないこと。

## 3. タイポグラフィ

- 和文フォント: Noto Sans JP
- 欧文フォント: system-ui
- フォールバック指定: -apple-system, "Segoe UI", sans-serif
- 基準フォントサイズ: 16px
- 行間（本文）: 1.7
- 行間（見出し）: 1.3

| 用途 | サイズ | 太さ |
|---|---|---|
| h1 | 28px | 700 |
| h2 | 22px | 700 |
| h3 | 18px | 700 |
| 本文 | 16px | 400 |
| 注釈 | 13px | 400 |

## 4. 余白

基準単位: 8px

| 変数名 | 値 | 用途 |
|---|---|---|
| --space-xs | 4px | |
| --space-sm | 8px | |
| --space-md | 16px | |
| --space-lg | 32px | |
| --space-xl | 64px | |

- セクション間の垂直余白: --space-xl (64px)
- 本文段落間の余白: --space-md (16px)

## 5. レイアウト

- コンテンツ最大幅: 760px
- 左右の最小余白（モバイル）: 16px
- グリッド: 単カラム
- 情報密度: 標準

## 6. ブレークポイント

| 名称 | 幅 |
|---|---|
| モバイル | 〜767px |
| タブレット | 768px〜1023px |
| デスクトップ | 1024px〜 |

## 7. その他の視覚要素

- 角丸: 4px
- 影: 使用しない
- 境界線の太さ: 1px
- アイコン: 使用しない（テキストと下線のみでリンク・強調を表現する）
- 画像の扱い: 16:9に統一、角丸なし
- アニメーション: 使用しない

## 8. 禁止事項

- グラデーションを使用しない
- 絵文字をアイコンの代用としない
- ホバー時の拡大縮小演出を行わない
- 影を複数階層で重ねない
